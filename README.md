# Personal Dashboard & Dynamic Live Clock

> A modern, responsive dark glassmorphism personal dashboard built with HTML5, vanilla CSS3, and JavaScript ES6+. Features dynamic greetings, real-time clock, customizable user profile, and interactive productivity widgets.

## 🌟 Key Features

- **⚡ Real-time Live Digital Clock**: Dynamic ticker updating every second with `12H` / `24H` format toggling, AM/PM indicator, full date, and local timezone offset (`UTC+08:00`).
- **👤 System & Custom User Profile**: Display name (default: `user`) and tagline with click-to-edit capabilities and `localStorage` persistence.
- **🌅 Time-of-Day Dynamic Greetings**: Automatically detects local time to display time-matched greetings (*Good Morning 🌅*, *Good Afternoon ☀️*, *Good Evening 🌆*, *Good Night 🌙*).
- **🎨 Glassmorphism Theme Switcher**: 4 curated themes (**Aurora Borealis**, **Cyberpunk**, **Obsidian Glass**, and **Sunset Glow**) with floating ambient glow orbs.
- **📌 Integrated GitHub Connections**:
  - **GitHub Project Board**: Direct card connection to [Project Board #1](https://github.com/users/kashak068/projects/1).
  - **GitHub Code Repository**: Direct card connection to [Repository kashak068 / 0916](https://github.com/kashak068/0916).
- **✅ Productivity Widgets**:
  - **Today's Focus**: Interactive task checklist with completion counters and item deletion.
  - **Daily Inspiration**: Tech & motivational quote generator with one-click copy to clipboard.
  - **World Clocks**: Live time tickers for New York, London, and Tokyo.
  - **Quick Launch Bar**: Instant links to GitHub Repo, Project Board, Profile, and AI Assistant.

## 🚀 Quick Start (Local Setup)

Clone the repository and serve locally using Python or any static web server:

```bash
# Clone the repository
git clone https://github.com/kashak068/0916.git

# Navigate to project folder
cd 0916

# Run local HTTP server
python -m http.server 8080
```

Open your browser and navigate to `http://localhost:8080`.
